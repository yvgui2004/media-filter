A media library that tags itself

会自己打标签的素材库

Built for editors, archivists and anyone sitting on a folder of clips they can't search.

给剪辑师、素材管理员，以及所有"有一堆素材但搜不出来"的人。

Local-first AI tagging本机 AI 识别

YOLOv8n runs locally on the GPU through DirectML (NVIDIA, AMD and Intel) with a CPU fallback: people, vehicles, pets, food, screens — 8 built-in tags without a single upload. Hybrid and cloud modes cover all 26, and you can add up to 10 custom labels such as 踢足球 or 王者荣耀.

YOLOv8n 通过 DirectML 在本机显卡上推理（NVIDIA、AMD、Intel，自动回退 CPU）：人物、车辆、宠物、食物、屏幕等 8 类标签无需上传；混合 / 云端覆盖 26 类，还能加最多 10 个自定义标签，如「踢足球」「王者荣耀」。

Batch processing, no syntax批量处理，不用写语法

One dialog: lossless remux, compression with x265 / x264 / NVIDIA NVENC / AMD AMF, or your own FFmpeg template. Preview every command, keep outputs collision-safe, and watch live progress with a result summary.

一个对话框：无损转封装、x265 / x264 / NVIDIA NVENC / AMD AMF 压缩，或自定义 FFmpeg 模板。每个文件都能预览命令，输出自动防冲突，执行时有实时进度和结果汇总。

Private by default默认保护隐私

Scanning is offline. The API key is encrypted with Windows DPAPI, keys are masked in logs, and nothing uploads before a confirmation card.

扫描全程离线；API Key 用 Windows DPAPI 加密，日志自动打码；上传前一定先弹确认卡。
