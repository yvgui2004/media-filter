标题：视频太多找不到？让 AI 先看一遍

剪过 vlog 的都懂：
文件夹里躺着几百条 VID_2024xxxx.mp4，
想找“上次拍的那条有狗有街景的”，只能一条条点开、拖进度条、关掉。

我干脆写了个 Windows 小工具：Media Filter
它做的事很简单——先替你把视频看一遍。

🔍 扫描：选个文件夹，自动读分辨率 / 时长 / 码率
🏷️ 打标签：本地 AI 识别画面，8 类标签（人 / 狗 / 车 / 食物 / 屏幕…），云端模式可扩到 26 类
⚡ 筛选：选「人」，一秒从 14 条剩 9 条
📦 批量：快速转换 / 压缩转码（NVENC / AMF / x265）/ 自定义命令，先看预览再执行

几个我在意的点：
· 识别在本地跑，有显卡（NVIDIA / AMD / Intel）自动走 DirectML 加速，没有就用 CPU
· 视频和关键帧都不上传，断网也能用
· 不用建项目、不搬文件，原地整理
· 免费开源（MIT），没有登录，没有会员
· 免安装，zip 解压双击就能用，约 168 MB

📖 上手 5 步：
1. GitHub 搜 media-filter（仓库 yvgui2004/media-filter），到 Releases 下 zip
2. 解压到任意目录，双击 MediaFilter.exe
3. 打开文件夹 → 点「AI 识别」，等进度走完
4. 顶部标签选「人」或「狗」，点「全选」
5. 点「批量处理」，选快速转换 / 压缩转码，先看命令预览，再复制 / 存 .bat / 开始处理

目前只支持 Windows 10 / 11 64 位。
AI 标签不是 100% 准，光线差、画面糊会漏，但比一条条点开快太多。
