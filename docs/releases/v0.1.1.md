# Media Filter 0.1.1 — Reliability release / 可靠性修复

**Portable Windows build.** Unzip it anywhere and double-click `MediaFilter.exe`. Python, FFmpeg and the local YOLOv8n model are bundled.
**Windows 便携版。** 解压到任意目录，双击 `MediaFilter.exe` 即可；Python、FFmpeg 与本地 YOLOv8n 模型都已内置。

## What changed / 本次更新

This release fixes the bugs that mattered in real use, all reproduced against a real FFmpeg build on Windows.
这次修的都是实际使用中会遇到的问题，全部在 Windows + 真实 FFmpeg 环境下复现并验证。

### Fixed / 修复

- **Batch commands with spaces in the path** now run correctly (`%` is escaped for `.bat` too), and failures report the FFmpeg stderr instead of looking successful.
  **带空格的批量命令**现在能正常执行（`.bat` 里的 `%` 也已转义），失败时会显示 FFmpeg 的错误输出，而不是装作成功。
- **Cancelling a scan is instant** — the running `ffprobe` is killed (measured 0.46 s instead of ~5 s).
  **取消扫描立即生效**：会直接结束正在跑的 `ffprobe`（实测 0.46 秒，而不是约 5 秒）。
- **Audio-only files are no longer treated as videos** and no longer show "识别失败" in the tags column.
  **纯音频文件不再被当成视频**，标签列不会再出现"识别失败"。
- **Local and cloud tag palettes are consistent**: the local model emits only the 8 tags it can recognise, cloud modes cover all 26, and the cache key includes the enabled set.
  **本地与云端标签体系统一**：本地只输出能识别的 8 类，云端覆盖 26 类，缓存键包含启用的标签集合。
- **Closing the window during a scan or tagging** now stops the workers cleanly.
  **扫描 / 识别过程中关闭窗口**会干净地停止工作线程。
- **Deleting rows** uses the Recycle Bin, refuses to delete in place when `send2trash` is missing, and keeps row indexes correct afterwards.
  **删除文件**走回收站；缺少 `send2trash` 时不会原地删除；删除后行索引保持正确。
- **Cloud endpoints are no longer hard-coded to localhost**, and requests retry without `reasoning_effort` when a server rejects it with HTTP 400.
  **云端接口不再写死本地地址**；服务器因 `reasoning_effort` 返回 400 时会自动去掉该参数重试。

### Added / 新增

- Rotating log at `%LOCALAPPDATA%\media-filter-v2\mediafilter.log` (1 MB × 3) with crash hooks — attach it to bug reports.
  循环日志 `%LOCALAPPDATA%\media-filter-v2\mediafilter.log`（1 MB × 3）与崩溃钩子，反馈问题时可直接附上。
- `python -m mediafilter [folder]` scans a folder on launch.
- Screenshots, a demo GIF and a landing page: <https://yvgui2004.github.io/media-filter/>
- CI on Windows (pytest + pyright), issue templates and `CONTRIBUTING.md` / `SECURITY.md`.

## Verification / 验证

- Manually verified batch execution with a quoted path containing a space.
