# Media Filter 0.2.1 — tick selection & popover polish / 勾选与弹层打磨

**Portable Windows build.** Unzip it anywhere and double-click `MediaFilter.exe`. Python, FFmpeg and the local YOLOv8n model are bundled.
**Windows 便携版。** 解压到任意目录，双击 `MediaFilter.exe` 即可；Python、FFmpeg 与本地 YOLOv8n 模型都已内置。

## What changed / 本次更新

### One selection state / 一种选中状态

- Rows are ticked directly: click anywhere on a row to tick or untick it. Dragging shows a transient preview — blue for “will tick”, a dashed outline for “will untick” — commits on release and clears the highlight, so the blue never lingers as a second kind of selection.
  行可以直接勾选：点行任意位置切换勾选。拖动时只显示临时预览——蓝色表示“将勾选”，灰色虚线框表示“将取消勾选”，松开即提交并清掉高亮，蓝色不会再作为一种额外的“选中”状态遗留。
- Batch processing and export use ticks only, show the tick count, and stay disabled when nothing is ticked.
  批量处理和导出只认勾选，显示勾选数量；没有勾选时两个按钮不可用。
- The context menu acts on the row under the cursor without changing ticks. Clear Ticks clears every tick, including files hidden by the current filter.
  右键菜单只作用于鼠标所在行，不会改变勾选；清空勾选会连被筛选隐藏的文件一起清空。

### AI mode popover / AI 模式弹层

- The popover now lands from the caret with a 170ms rise; its three cards fade in 20ms apart and the eight-cell upload strips sweep in lockstep (local 0, hybrid 3, cloud 8). Picking a mode pulses the card, re-sweeps its strip, fades the mode word to the new label and retracts after a short beat. The caret rotates instead of swapping icons, and the hybrid-without-labels warning unfolds by height.
  弹层从箭头下方升起（170ms），三张卡片错峰 20ms 淡入，三条 8 格上传范围帧带同拍扫入（本地 0、混合 3、全云端 8）。点选后卡片亮起扩散、帧带重扫、按钮上的模式词淡出换字，短暂停留后收回；右侧箭头旋转而不是换图标；混合模式缺标签时的提示条以高度动画展开。
- The menu's layout now matches the design prototype: 73px cards, a 35px header, a 24px warning row, 7px scope strips, the sliders icon and 12px chevrons in the footer, and the prototype's wording（本地 / 仅匹配 / 回退本地）.
  弹层排版按设计稿对齐：73px 卡片、35px 头部、24px 提示条、7px 帧带；页脚换成滑杆图标与 12px 箭头，文案统一为「本地 / 仅匹配 / 回退本地」。

### Fixed / 修复

- The batch dialog's **高级选项** row could not be opened; the disclosure row now receives mouse and keyboard input.
  批量处理对话框的 **高级选项** 打不开：展开行现在能响应鼠标和键盘。
- The portable executable's version resource now tracks the release version.
  便携版 exe 的版本资源现在跟随发布版本号。
