# Media Filter 0.2.0 — GPU tagging & batch processing / GPU 识别与批量处理

**Portable Windows build.** Unzip it anywhere and double-click `MediaFilter.exe`. Python, FFmpeg and the local YOLOv8n model are bundled.
**Windows 便携版。** 解压到任意目录，双击 `MediaFilter.exe` 即可；Python、FFmpeg 与本地 YOLOv8n 模型都已内置。

## What changed / 本次更新

### GPU inference / 显卡加速

- Local tagging now runs through ONNX Runtime **DirectML**, so NVIDIA, AMD and Intel GPUs accelerate the same YOLOv8n model.
  本地识别改用 **DirectML**，NVIDIA、AMD、Intel 显卡都能加速同一个 YOLOv8n 模型。
- Advanced settings offers **Auto / CPU / GPU**, shows the detected adapter, skips the WARP software renderer and falls back to CPU if the GPU session cannot start.
  高级设置可选 **自动 / CPU / GPU**，显示检测到的显卡，跳过 WARP 软件渲染器；GPU 初始化失败会自动回退 CPU。
- **Colour tags for cats, dogs and cars** are sampled locally (`黑猫`, `白狗`, `白车`): the detection box is cropped to the animal centre or vehicle body band, converted to HSV with NumPy, and voted across frames. The switch is in advanced settings.
  **猫、狗、车的颜色标签**在本地采样（`黑猫`、`白狗`、`白车`）：把检测框裁到动物中心或车身区域，用 NumPy 转 HSV，多帧投票。开关在高级设置里。

### One batch-processing dialog / 统一的批量处理

- The separate **批量命令** and **格式转换** buttons are merged into one **批量处理** dialog with three task cards: **快速转封装**, **压缩转码** and **自定义命令**.
  原来的 **批量命令** 和 **格式转换** 合并成一个 **批量处理** 对话框，三张任务卡：**快速转封装**、**压缩转码**、**自定义命令**。
- Encoders: x265 / x264 CRF tiers, **NVIDIA NVENC** (HEVC / H.264 / AV1, CQ/QP) and **AMD AMF** (HEVC / H.264 / AV1, QP), with automatic detection and a CPU fallback when hardware encoding fails.
  编码器：x265 / x264 的 CRF 档位、**NVIDIA NVENC**（HEVC / H.264 / AV1，CQ/QP）、**AMD AMF**（HEVC / H.264 / AV1，QP），自动检测，硬件编码失败可回退 CPU。
- Output is planned collision-safe: temp files first, atomic replace on success, number / skip / overwrite modes, and an input is never overwritten.
  输出路径防冲突：先写临时文件，成功后原子替换；重名可选加序号 / 跳过 / 覆盖；永远不会覆盖输入文件。
- The dialog previews the exact FFmpeg command per file, shows overall and per-file progress, supports cancel, and summarises successes, failures and size savings. Commands can be copied or saved as `.bat`; failed items can be copied as a list.
  对话框会预览每个文件的实际命令，显示总进度和单文件进度，支持取消，结束后汇总成功、失败与体积变化。命令可复制或存成 `.bat`，失败清单也可复制。
- Advanced options cover audio (smart copy / copy / AAC / Opus / remove), subtitles, target container, encoder preset, failure strategy (continue / stop), metadata and chapters, and the custom template.
  高级选项涵盖音频（智能复制 / 复制 / AAC / Opus / 移除）、字幕、目标容器、编码器预设、失败策略（继续 / 停止）、元数据与章节，以及自定义模板。

### Fixed / 修复

- Switching tasks in the batch dialog resets the form to the top.
  批量处理切换任务时，表单会回到顶部。
- The advanced-options summary line hides while the panel is expanded.
  展开高级选项后不再重复显示摘要行。
